# i18n-baseline/de.untranslated.txt
#
# Baseline of core (universal-till web/locales/en.json) keys this German
# pack does NOT yet translate -- known, accepted debt, not a bug.
#
# scripts/check-key-drift.sh fails if any key listed here has since been
# translated (stale baseline -- prune it) or if core has dropped it (also
# prune it), and it fails if core gains an untranslated key that is NOT
# listed here (new drift -- either translate it or add it here
# deliberately). That means this set cannot grow SILENTLY: it can only grow
# through a deliberate, reviewed edit to this file, and any such edit shows
# up in the diff. This is NOT a shrink-only ratchet -- adding a key here on
# purpose is the guard's documented escape hatch, not a violation of it.
# This distinction is exactly the bug class that produced ut-docs#292: six
# pfand.* keys were added to core, never added here, and the till silently
# fell back to English with no CI signal anywhere.
#
# One key per line, sorted, unique -- enforced by check-key-drift.sh (a
# baseline that isn't sorted/deduped fails the same way a stale entry does).
# Regenerate with:
#   scripts/check-key-drift.sh --update-baseline
# (reuses the same resolved-core-path logic as the check itself: set
# UT_CORE_EN_JSON=<path> to regenerate against a local core checkout
# offline, or let it fetch from CORE_EN_URL / UT_CORE_EN_URL.)
