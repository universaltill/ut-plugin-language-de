## Meaning
A read-only COPY of the shop's sales and day closes on each additional till, so one can take over as main till. Not a backup, not a sync.

## Term choices (reused from this pack)
Hauptkasse (main till), zusätzliche Kasse (additional till), Satellit, Kopie (copy), Tagesabschluss (day close), Z-Bericht, koppeln (pair), storniert (voided), Berichte (Reports), Bestand (stock), Belegnummern (receipt numbers).

### Findings
1. Low, fixed: `tills.sales_mirror.help`: "hält eine Kopie", "als Hauptkasse übernehmen" and "zählt nie in den Summen" read as literal translations. Now "speichert eine schreibgeschützte Kopie … ohne Verlust die Rolle der Hauptkasse übernehmen kann. Ein kopierter Verkauf fließt nie in die eigenen Summen, den Z-Bericht, den Bestand oder die Belegnummern dieser Kasse ein."
2. Low, fixed: `tills.promote_outside_z`: "die in keinem Z-Bericht stehen könnten" was ambiguous, and "letzten Abschluss" was vaguer than the pack's usual "Tagesabschluss". Now "vor dem letzten Tagesabschluss der bisherigen Hauptkasse, die möglicherweise in keinem Z-Bericht enthalten sind".
3. Low, fixed: `tills.promote_adopt_resumes`: in "sie bleibt erhalten" it was unclear whether "sie" meant the copy or the takeover. Now "die Kopie bleibt erhalten, und die Übernahme wird innerhalb weniger Minuten automatisch abgeschlossen."
4. Nit, fixed: `tills.sales_mirror.state.needs_tls`: changed to the shorter chip "Sichere Verbindung nötig: diese Kasse neu koppeln".
5. Nit, accepted: `tills.promote_adopted` uses "Verlauf" for "record". The pack already uses this word for a till's own history (join warning), so it stays. `promote_adopt_failed` says "Problemliste" where the UI heading is "Aktuelle Probleme". This is understandable, and the English text is also generic.

### Verdict
Safe to merge once the fixes above are committed. The terms (Hauptkasse, zusätzliche Kasse, Satellit, Tagesabschluss, Z-Bericht, koppeln, storniert, Berichte, Bestand, Belegnummern) match the pack.
